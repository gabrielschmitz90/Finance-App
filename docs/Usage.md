Uso
===

Dashboard
---------
- Abra [Dashboard/dashboard.html](Dashboard/dashboard.html) no navegador.
- O arquivo `dashboard.js` contém a lógica principal para interações.
- `dashboard-old.js` é uma versão anterior; revisar antes de remover.

Timeline
--------
- Abra [Timeline/index.html](Timeline/index.html).
- `script.js` controla a renderização da linha do tempo.

Dicas
-----
- Teste alterações de script recarregando a página.
- Para depuração, abra as DevTools do navegador (F12).
