Visão Geral
===========

Objetivo
--------
Fornecer uma interface simples para visualizar informações financeiras e eventos ao longo do tempo.

Funcionalidades principais
--------------------------
- Dashboard: visualização de métricas e gráficos (front-end estático).
- Timeline: exibição cronológica de eventos/lançamentos.

Público-alvo
-----------
Usuários que precisam acompanhar indicadores financeiros e eventos relacionados.

Limitações
----------
- Não há persistência de dados (não há backend configurado).
- Foco em protótipo/frontend estático.
