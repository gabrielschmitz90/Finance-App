Instalação e Execução
======================

Requisitos
---------
- Navegador moderno (Chrome, Edge, Firefox)
- (Opcional) Python 3 para servir arquivos localmente

Executando localmente
---------------------
1. Abra a pasta do projeto no seu sistema de arquivos.
2. Opção direta: abra `Dashboard/dashboard.html` ou `Timeline/index.html` no navegador.
3. Opção servidor (recomendado):

```
cd path/to/Finance-App
python -m http.server 8000
```

Acesse `http://localhost:8000/`.

Notas
-----
- Se usar servidores estáticos alternativos, a raiz do servidor deve ser a pasta `Finance-App`.
