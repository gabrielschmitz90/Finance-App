Finance-App
=============

Resumo
------
Aplicação simples contendo um painel (`Dashboard`) e uma linha do tempo (`Timeline`) para visualização de dados financeiros e eventos.

Estrutura do projeto
--------------------
- Dashboard/: código do painel
- Timeline/: código da linha do tempo

Como executar
-------------
Esta é uma aplicação estática (HTML/CSS/JS). Para rodar localmente:

Opção 1 — Abrir no navegador
- Abrir `Dashboard/dashboard.html` ou `Timeline/index.html` diretamente no navegador.

Opção 2 — Servidor simples (recomendado)
- Usando Python 3:

```
cd Finance-App
python -m http.server 8000
```
- Abrir `http://localhost:8000/` no navegador.

Tecnologias
-----------
- HTML, CSS, JavaScript (vanilla)
